# ADR-009：权限 profile 与跨平台沙箱

- 状态：Accepted
- 日期：2026-07-29

## 决策

继承 Codex permission profile、approval、exec policy、network policy 和跨平台 sandbox 抽象。首版公开 Read Only、Workspace 和 Full Access 三类清晰 profile；`danger-full-access` 必须显式选择，不能由 provider 或 Skill 自动升级。

Windows 使用 restricted token/sandbox 实现，Linux 使用 Landlock/bubblewrap 等固定基线能力，macOS 保留 Seatbelt 边界。所有平台在执行前使用同一策略判定，平台后端只负责落实策略。

## 后果

- 远程 MCP/HTTP 默认不能读取整个 workspace；
- 越界写、网络和危险命令分别审批；
- 拒绝结果进入世界状态，禁止形成重复审批循环；
- 沙箱降级必须可见且可审计，不能静默变为 Full Access。
