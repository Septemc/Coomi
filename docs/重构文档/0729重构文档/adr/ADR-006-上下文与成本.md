# ADR-006：上下文预算与成本门槛

- 状态：Accepted，动态指标待测
- 日期：2026-07-29

## 决策

所有模型可见片段必须有来源、token 计量、硬上限和淘汰顺序。保留 Codex 稳定前缀、增量 world state、Responses continuity 和 compact；Coomi 增加请求级成本账本、工具 schema 预算和功能 context tax。

发布门槛沿用主计划第 4.3/19.6 节：同模型任务 P50 输入相对 Python Coomi 至少降低 35%，简单无工具任务至少降低 50%，相对固定 Codex 总输入不高于 110%，未选择 MCP schema 为 0，同状态重复工具调用不高于 2%。

## 未关闭事项

默认 token 数值在 B01-B10 动态基线后确定，不能凭静态字符数拍板。真实 endpoint/model benchmark 会产生费用，必须先获得费用授权。未完成动态数据前，本 ADR 只冻结计量方式和发布门槛，不宣称已达到成本目标。
