# ADR-012：许可证和上游来源管理

- 状态：Accepted
- 日期：2026-07-29

## 决策

顶层 Coomi 原有代码继续使用仓库 MIT License。导入的 OpenAI Codex Rust 快照遵守 Apache-2.0，完整文本保存在 `LICENSES/Apache-2.0.txt`，上游 NOTICE 内容保存在 `LICENSES/OpenAI-Codex-NOTICE.txt`，来源和修改声明保存在 `THIRD_PARTY_NOTICES.md`、`UPSTREAM_CODEX.md` 和 `UPSTREAM_CODEX.toml`。

## 后果

- 发布包必须携带顶层 LICENSE、Apache-2.0 文本和第三方 NOTICE；
- 上游 commit、导入目录和校验结果必须可追溯；
- 删除源码不能删除仍适用于二进制的第三方声明；
- 新依赖继续通过 Cargo lock/deny/audit 管理；
- 本 ADR 是工程合规决策，不替代正式法律意见。
