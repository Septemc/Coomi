# ADR-007：Tool Spec Plan 与重复调用不变量

- 状态：Accepted
- 日期：2026-07-29

## 决策

每个 Turn 在本地根据意图、mode、权限、workspace、Skill/MCP 激活状态和模型能力生成 Tool Spec Plan。该计划不额外调用模型，只决定本轮暴露哪些工具与 schema。

工具调用指纹至少包含 tool name、canonical arguments、相关 world-state revision 和权限状态。同一指纹在状态未变化时不得重复执行，除非工具声明为幂等轮询且未超过轮询预算。

## 后果

- 权限拒绝、确定性失败和空结果必须成为状态，避免模型盲重试；
- 写工具按 workspace 冲突域串行化，读工具可受控并行；
- 预算耗尽返回可恢复的明确终止原因；
- 重复拦截进入 rollout 和成本账本。
