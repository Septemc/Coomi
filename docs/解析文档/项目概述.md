# Coomi Agent — 项目概述

> 生成日期：2026-05-23

---

## 一、项目定位

Coomi (Coomi Agent) 是一个参考 Claude Code 设计的 AI 编程助手（AI Agent），通过 CLI 交互，支持工具调用、记忆系统和上下文压缩。其核心是一个 **感知-决策-行动** 的自主循环：LLM 自主决定读文件、改代码、执行命令还是回复用户。

## 三、核心流程

### 3.1 Agent 主循环（engine/loop.py）

```
用户输入 → 压缩检查 → LLM 调用
     ↓                     ↓
  (如果压缩)          ┌── 有工具调用？── 执行工具 → 缓存 → 返回结果
                     │                           ↓
                     │                   中轮压缩检查 → 继续循环
                     └── 无工具调用 → 返回文本响应
```

- **流式版本** (`run_stream`)：支持逐个字符流式输出 + 工具调用通知
- **非流式版本** (`run`)：完整响应后返回

### 3.2 System Prompt 构建（engine/session.py）

```
[静态部分]  ← 角色定义 / 安全红线 / 行为准则 / Git 安全 / 输出风格
───────────────────── 分割线 ─────────────────────
[动态部分]
 ├─ 环境信息（工作目录、OS、Shell、日期、模型）
 └─ 持久记忆（完整内容注入或语义召回结果）
```

### 3.3 上下文压缩（services/context/compressor.py）

三层压缩策略，对齐 Claude Code：

| 层级 | 名称 | 行为 | API 开销 |
|------|------|------|---------|
| Layer 1 | Microcompact | 清理老工具结果（>6条的内容替换为标记） | 零 |
| Layer 2 | 消息裁剪 | 保留第1条 + 最近8条消息 | 零 |
| Layer 3 | LLM 摘要 | 用当前模型生成9段结构化摘要 | 有 |

触发条件：实时估算 token > 上下文窗口 × 90%

### 3.4 记忆系统（services/memory/）

```
三层存储：
  ~/.coomi/memory/                    ← 全局记忆（始终加载）
  ~/.coomi/projects/{hash}/memory/    ← 项目级全局存储
  .coomi/memory/                      ← 项目本地（最高优先级）

每轮流程：
  对话 → [MemoryExtractor] 自动提取 → 保存到文件
  输入 → [MemoryRecall] 语义召回 → 注入 System Prompt
```

记忆类型：`user`（偏好）、`feedback`（反馈）、`project`（项目）、`reference`（资源）

### 3.5 工具结果缓存（services/context/cache.py）

- 大结果（>50KB）自动存盘到 `~/.coomi/cache/tool_results/`
- 缓存有效期 7 天
- 支持项目级缓存（`<project>/.coomi/cache/`）

## 四、LLM Provider 层

通过抽象基类 `LLMProvider` 统一接口：

| 方法 | 说明 |
|------|------|
| `chat()` | 同步调用 |
| `chat_stream()` | 纯文本流式输出 |
| `chat_stream_with_tools()` | 流式输出 + 工具调用 |
| `switch_model()` | 运行时切换模型 |
| `get_model_display_name()` | 获取显示名称 |

支持三种模式：`NATIVE`（原生工具调用）、`JSON`（降级方案）。

当前默认 Provider：**DeepSeek**（V4 Pro / Flash 切换）。

## 五、工具系统

通过 `ToolRegistry` 注册/管理所有工具：

| 工具 | 访问权限 | 说明 |
|------|---------|------|
| ReadTool | 只读 | 读取文件 |
| WriteTool | 写入 | 创建/覆写文件 |
| EditTool | 写入 | 精确字符串替换 |
| GlobTool | 只读 | 文件模式匹配 |
| GrepTool | 只读 | 内容搜索 |
| BashTool | 写入 | 执行 Bash 命令 |
| PowerShellTool | 写入 | 执行 PowerShell |
| WebFetchTool | 只读 | 获取 URL 内容 |
| WebSearchTool | 只读 | 搜索网络 |
| TodoWriteTool | 写入 | 任务列表管理 |
| AgentTool | 写入 | 启动子 Agent |
| AskUserQuestionTool | 只读 | 向用户提问 |
| EnterPlanModeTool | 写入 | 进入 Plan 模式 |
| ExitPlanModeTool | 写入 | 退出 Plan 模式 |
| ConfigTool | 写入 | 修改配置 |

## 六、CLI 界面

### 命令列表

| 命令 | 说明 |
|------|------|
| `/model [pro\|flash]` | 切换模型 |
| `/context [256k\|512k\|1m]` | 设置上下文窗口大小 |
| `/memory list\|add\|delete\|search\|show\|refresh` | 记忆管理 |
| `/clear` | 清空会话 |
| `exit` / `quit` | 退出 |

### 流式 UI

- 瀑布流 Markdown 渲染（Rich Live）
- 工具调用实时通知（工具名 + 参数）
- 缓存命中提示
- 压缩通知（压缩前/后消息数）
- 最终状态栏（token 使用量）
